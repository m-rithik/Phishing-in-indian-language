          About, limitations & privacy

          Local by design. Fisher checks only content you paste or page text you explicitly select. The right-click "Check selection with Fisher" item sends only the text you selected, held in memory for about 30 seconds, or until the browser stops the extension worker, until the popup reads it, with no automatic scanning. The selection can include text inside iframes. It makes no network requests and keeps no input history. Permissions are strictly activeTab, contextMenus, and scripting. Saving a report downloads generic findings only.

          Know the limits. This is a deterministic pattern checker, with a small set of English, Hindi, Tamil, Telugu, and Romanized Indic rules. Language coverage and accuracy are unmeasured. A quiet result does not mean content is safe.

          Links stay closed. Checks describe address structure and immediate destinations embedded in recognized navigation fields. They do not verify reputation, ownership, or where a redirect actually leads. HTTPS alone does not establish legitimacy.

          Batch review. Each physical line is checked independently. Blank or invalid lines receive a “could not analyze” result. File imports stay in this window and wait for you to start analysis. A cancelled run produces no completed batch report.

          Your window, your draft. Drafts last only while this window is open. When opened from the header, an expanded workspace starts empty; a workspace tab opened from the menu starts with the selected text analyzed but never copied into the draft. Page selection is available from the toolbar popup.

          Made for the moment before you click.
