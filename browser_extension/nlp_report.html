🎯 How It Works

  1. You visit a website
  2. Fisher automatically extracts visible text
  3. Detects page language (English, Hindi, Tamil, etc.)
  4. Scans for threat patterns:
    • ⚠️ Urgency words (तुरंत, suspend, immediately)
    • 🔐 Credential requests (OTP, खाता संख्या, CVV)
    • 📞 Phone requests (call now, contact)
  5. Calculates risk score:
    • If urgency + credentials → HIGH-RISK 🚨
    • If only some patterns → REVIEW ⚠️
    • If no patterns → SAFE ✓
  6. Shows banner with detected keywords
  7. Updates icon badge with risk level
